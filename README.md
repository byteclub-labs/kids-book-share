# kids-book-share
Simple website for parents in our society to share kids books: post available books, request, confirm and collect.

## Run

```bash
npm install
npm start
```

Then open http://localhost:3000 — post a book with your name and flat/unit, and other parents will see it after a refresh. Data is stored in `data/books.json` (override with `DATA_DIR`, port with `PORT`).
